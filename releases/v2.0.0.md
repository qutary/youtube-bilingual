# v2.0.0 · 多语言字幕与界面翻译

在 YouTube 官方 iPhone / iPad App 中，用你选择的语言阅读字幕、标题、简介和评论。

## 新增与改进

- 支持中文、英语、日语、韩语、法语、俄语、德语、葡萄牙语、西班牙语、意大利语、印地语、泰语、阿拉伯语。
- 提供译文在上、原文在上、仅译文三种显示方式，字幕与界面共用目标语言和显示方式。
- 翻译已适配的首页、搜索、播放页、推荐、简介、评论、频道、帖子、播放列表、历史记录与部分 Shorts 文字，可按类别关闭。
- DeepSeek、火山方舟、OpenRouter、自定义 OpenAI 兼容 API 均接入字幕与界面翻译，使用当前所选服务。
- QX 与 Shadowrocket 统一通过 BoxJS 设置，提供中文和英文设置页。
- 集成本地译文缓存、一次清理和 YouTube 广告处理。未完成的内容保留原文，后续请求可尝试补齐。

## 安装与升级

[中文安装说明](https://github.com/qutary/youtube-bilingual-subtitles#install) · [English guide](https://github.com/qutary/youtube-bilingual-subtitles/blob/main/README.en.md#install)

**请同时更新模块／重写和项目 BoxJS 订阅，停用旧版或重复的 YouTube 规则，保留已保存数据。**

- 从旧 Shadowrocket 模块参数版升级，需安装 BoxJS 并保存原 Key、模型等参数；旧模块参数不会自动迁入。
- 已使用 BoxJS 的用户可保留保存值；QX 和 SR 各自存储设置，不自动同步。
- 并发默认 20、范围 1–256；字幕等待默认 6.3 秒、范围 3–10 秒，已保存的手动值保留。
- 更换中英文设置页不改变目标语言，也不需要重填已保存在本应用 BoxJS 的 Key。

### v2.0.0 固定版本入口

- [Quantumult X 重写](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/v2.0.0/qx/YouTube.Bilingual.snippet)
- [Shadowrocket 模块](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/v2.0.0/shadowrocket/YouTube.Bilingual.shadowrocket.module)
- [中文 BoxJS](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/v2.0.0/qx/youtube-bilingual.boxjs.json)
- [English BoxJS](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/v2.0.0/qx/youtube-bilingual.en.boxjs.json)

字幕需要视频提供原字幕轨；页面、字幕质量、网络和模型会影响翻译效果。API 费用由所选服务商收取。

保留 [v1.6.0](https://github.com/qutary/youtube-bilingual-subtitles/releases/tag/v1.6.0) 和 [v1.5.0](https://github.com/qutary/youtube-bilingual-subtitles/releases/tag/v1.5.0) 的历史版本，回退前先停用当前规则。

## English

v2.0.0 adds captions across 13 languages, three display modes, supported interface text translation, and four API options for both captions and interface content. QX and Shadowrocket now share a BoxJS settings template, with Chinese and English editions.

Update both the module/rewrite and the project BoxJS subscription. Keep saved data and disable older or duplicate rules. Users upgrading from older Shadowrocket module arguments must enter their existing key and model in BoxJS once. Each proxy app stores settings separately.

Captions require an available original track. Translation depends on the client layout, network and selected model. See the English guide above for installation and troubleshooting.
