# v1.5.0 — 历史版本

这是 v1.6.0 之前的正式版本，现已保留为可回退的历史版本。

## ✨ New Features

- 在 YouTube 官方 iPhone / iPad App 内显示中英双语字幕，支持双语和仅中文字幕模式。
- 支持 Quantumult X（通过 BoxJS 配置）与 Shadowrocket（通过模块参数配置）。
- 支持 DeepSeek、火山方舟、OpenRouter 等翻译服务，并提供字幕翻译缓存。

## 🐛 Bug Fixes

- 提供字幕请求处理和翻译异常时的英文原字幕回退机制。
- 通过缓存复用已完成的翻译，减少重复请求。

## 🔄 Other Changes

- **保留完整的 v1.5.0 版本**，方便在新版不适用时回退。
- 回退安装文件内部已锁定旧版脚本，不会自动切换到最新的 `main`。

## 📦 历史版本安装

- [Quantumult X · v1.5.0 固定订阅](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/main/releases/pinned/v1.5.0/YouTube.Bilingual.snippet)
- [Shadowrocket · v1.5.0 固定模块](https://raw.githubusercontent.com/qutary/youtube-bilingual-subtitles/main/releases/pinned/v1.5.0/YouTube.Bilingual.shadowrocket.module)

如需使用最新版，请查看 [v1.6.0](https://github.com/qutary/youtube-bilingual-subtitles/releases/tag/v1.6.0)。

**注意：** 回退时请停用其他版本的字幕模块或重写规则；已保存的 API 配置不需要重新填写。
