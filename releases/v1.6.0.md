# v1.6.0 — ASR Context & Display V3

发布日期：2026-11-08 · Quantumult X / Shadowrocket · 正式版本（后续兼容性反馈持续收集）

## ✨ New Features
- **语义与显示分组分离**：先保留完整英文语义窗口供翻译理解，再按短屏幕显示片段做中文对齐；不再先把长句切碎成独立翻译 ID。
- **更适合自动生成字幕的显示规划**：滚动字幕源 `w=` 边界不再优先作为语义断点，并改进英语词组、助动词、限定词等附近的切分打分。
- **较小的英文字幕样式**：默认英文 SRV3 `sz` 参数从 `140` 调整为 `100`，中文保持 `110`，减少小屏占用。具体视觉尺寸仍由 YouTube 原生 App 决定。

## 🐛 Bug Fixes
- 减少 `black / hole`、`direct / confrontation`、`span / of` 等实际案例中的不自然断句。
- 新协议要求每个语义窗口返回与固定显示片段一一对应的中文，校验词序覆盖和中文范围，避免验证阶段重新合并成大段字幕。
- 当中文请求未完成或返回无效时，英文回退也保留已规划的短显示单元，避免退回有问题的 ASR 滚动边界。

## 🔄 Other Changes
- QX 与 Shadowrocket 核心同步更新；保持原来的正式订阅路径、BoxJS 设置字段和模块参数。
- 新译文映射使用独立缓存指纹 `SEM_V4_CONTEXT1`，以避免沿用旧分句映射；不会主动清空已有其他缓存。
- 私有开发仓库与独立日志保留完整问题分析、修复和测试记录；正式 README 保持用户使用说明为主。

## 🧪 验证与已知限制
- 已对用户提供的人工/自动字幕 HAR 摘要进行离线回归，包括《Interstellar》时间膨胀视频和北约视频；两端静态语法、英文文本保留、分组映射与模拟 API→缓存→SRV3 渲染检查通过。
- **尚未完成真实 DeepSeek API 在全视频与所有 iOS 设备上的验收**。ASR 原文中的识别错误（如 `ganua`）不会自行改正；缺乏逐词时间戳时，部分内部时间切点仍为估算。
- 如出现加载慢、译文提前/滞后或双语错位，可回退到 [v1.5.0](v1.5.0.md) 并提交脱敏日志。
