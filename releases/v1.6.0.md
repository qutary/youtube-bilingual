# v1.6.0 — 双语字幕显示与断句优化

本次更新重点改善 YouTube 原生 iPhone / iPad App 的中英双语字幕体验，尤其是自动生成英文字幕的断句和中文翻译对应。

## ✨ New Features

- **更紧凑的双语排版**：适当缩小英文字幕，减少长句占据画面的情况，保持中文在上、英文在下的显示方式。
- **结合上下文翻译**：翻译时保留较完整的英文语义，再划分为适合屏幕阅读的字幕片段。
- **优化自动字幕分句**：减少直接沿用 YouTube 滚动字幕边界造成的不自然断句。

## 🐛 Bug Fixes

- 改善英文词组被拆到不同字幕中的问题，让断句更符合自然表达。
- 缓解中文译文与英文片段不对应、中文出现孤立残句的情况。
- 当部分中文翻译暂时不可用时，英文字幕仍尽量保持合理的短句显示，避免突然恢复成大段文字。

## 🔄 Other Changes

- **Quantumult X 与 Shadowrocket 同步更新**，原有正式订阅地址保持不变。
- 保留现有 BoxJS 配置、模块参数和 API Key；旧缓存不会被主动清空。
- 保留 [v1.5.0 历史版本](https://github.com/qutary/youtube-bilingual-subtitles/releases/tag/v1.5.0)，可以按需回退。

## 📦 安装与更新

- [Quantumult X 安装说明](https://github.com/qutary/youtube-bilingual-subtitles/blob/main/qx/README.md)
- [Shadowrocket 安装说明](https://github.com/qutary/youtube-bilingual-subtitles/blob/main/shadowrocket/README.md)

已安装的用户只需更新原有订阅或模块。更新前请停用其他版本的 YouTube 字幕重写，避免重复生效。

**使用提示：** 自动生成字幕可能含有 YouTube 本身的语音识别错误；如视频提供人工制作的 English 字幕，优先选择人工字幕。字幕实际效果还会受 YouTube 客户端和视频字幕质量影响。
