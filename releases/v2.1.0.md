# v2.1.0 · 手机推荐翻译与自动推理适配

## 更新内容

- 补齐手机播放页、后续推荐列表和部分播放器卡片的标题翻译，支持首页卡片摘要。
- 频道名、播放量和发布时间默认保留原样；频道简介仍可翻译。
- DeepSeek、火山方舟、OpenRouter、自定义 OpenAI 兼容接口统一自动管理推理：能关闭时优先关闭，模型强制要求时使用最低可识别的支持档位。
- 移除推理强度设置，不需要手动选择自动、关或开。旧推理设置不再影响运行。
- 改善推理参数兼容与失败提示；无法可靠识别最低档位时保留原文，不擅自启用高档推理。
- QX 和 Shadowrocket 同步更新，中英文设置与说明同步。推荐使用 DeepSeek。

## 安装与升级

[中文指南](https://github.com/qutary/youtube-bilingual#install) · [English guide](https://github.com/qutary/youtube-bilingual/blob/main/README.en.md#install)

**同时更新模块／重写与项目 BoxJS 订阅，停用旧版或重复规则，保留已保存数据。** 无需重填已在本应用 BoxJS 保存的 Key；QX 与 SR 的数据分别存储，不自动同步。

使用测试版固定链接的用户，请换成 README 中的正式订阅地址。保存后重新进入视频或相关页面；已加载的 YouTube 内容不会实时刷新。

## English

v2.1.0 improves mobile recommendation titles and feed summaries. Channel names, view counts and publication dates remain unchanged, while channel biographies can still be translated.

All four API profiles now manage reasoning automatically, preferring off and using the lowest identifiable supported effort only when required. The reasoning selector has been removed and previous reasoning settings are ignored. DeepSeek is recommended.

Update both the module/rewrite and the BoxJS subscription, keep saved data, and disable older duplicate rules. Replace test URLs with the stable URLs in the guide. Models and custom APIs vary in their available controls; original text is preserved when the required minimum cannot be identified safely.
