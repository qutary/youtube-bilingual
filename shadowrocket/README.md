# Shadowrocket 安装与使用

当前正式版为 **v2.0.0**，字幕、界面翻译和广告处理已集成，参数统一通过 BoxJS 设置。

- [安装与配置](../README.md#install)
- [翻译设置](../README.md#settings)
- [常见问题](../README.md#faq)
- [English guide](../README.en.md#install)

从旧版升级时需安装 BoxJS，并在本应用的 BoxJS 保存原 Key、模型等参数。模块旧参数不会自动迁入；已有 BoxJS 参数可继续使用。更新模块及项目设置订阅后，停用旧版及重复规则。
